# Educación Media Superior — Materiales Didácticos

Repositorio de materiales didácticos para el bachillerato (educación media superior) en México. Este proyecto constituye un **portafolio de preparación docente**.

Enfocado en pensamiento matemático, álgebra, geometría analítica, cálculo diferencial e integral, probabilidad, estadística, lógica, programación y desarrollo de software. 

Recursos organizados por asignatura que incluyen explicaciones, ejemplos resueltos, actividades prácticas y aplicaciones tecnológicas orientadas al aprendizaje.
